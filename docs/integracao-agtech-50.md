**Ekonomática | Site e Portfólio de IA:** manter serviços, evidências técnicas, demonstrações, canais de contato e conteúdo institucional atualizado.

## Fluxo de encaminhamento
1. Identificar empresa, vaga/necessidade e fonte da oportunidade.
2. Selecionar projetos relevantes para aquela demanda; evitar apresentar todo o portfólio indiscriminadamente.
3. Incluir nas apresentações o link do site **somente após publicação verificada**, além do GitHub e do e-mail comercial.
4. Registrar no Agtech +50 a oportunidade, data, canal e status real (enviado, aguardando resposta, respondeu, reunião etc.).
5. Quando houver feedback pertinente ao portfólio, atualizar conteúdo público no GitHub após conferir a informação.
6. Usar informações dos projetos apenas quando verificadas; não divulgar código sensível, credenciais, nomes de leads, dados internos ou resultados comerciais não comprovados.
