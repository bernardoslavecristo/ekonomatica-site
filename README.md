# Ekonomática — Site institucional

Site estático responsivo da Ekonomática, com portfólio, soluções, apresentação institucional e contato comercial.

## Conteúdo
- ChefLú — demonstração de atendimento conversacional e automação WhatsApp
- Kaggriculture AI — agente autônomo em simulação agrícola, protótipo
- Impact Hub — desafio técnico de automação de notas fiscais (não implica implantação comercial)
- Simulador de Aluguéis — projeto imobiliário com parâmetros e cenários de simulação
- Nilo — projeto em revisão de documentação pública

## Como executar
Abrir `index.html` em navegador. Não requer servidor, build, dependências ou credenciais.

## Publicação
Workflow em `.github/workflows/pages.yml` dispara no push para `main`.
Em **Settings → Pages → Build and deployment → Source**, selecionar **GitHub Actions**.
Após a primeira execução bem-sucedida, conferir a URL informada pelo GitHub Pages em Settings → Pages.
